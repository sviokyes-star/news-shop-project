# Rock The Vote (RTV)

Плагин для Counter-Strike 2: игроки командой голосуют за смену карты, а при наборе нужного числа голосов запускается голосование за следующую карту.

## Как это работает

1. Игрок пишет в чат `rtv` — его голос за смену карты учитывается.
2. Когда «за» проголосовало **60%** игроков онлайн, запускается голосование за карту.
3. Всем показывается меню из до 5 карт (сначала номинированные, затем случайные из пула). На выбор — 20 секунд.
4. Побеждает карта с наибольшим числом голосов — сервер меняет карту через 5 секунд.

## Команды

| Команда | Описание |
|---|---|
| `rtv` / `css_rtv` | проголосовать за смену карты |
| `unrtv` / `css_unrtv` | отозвать свой голос |
| `nominate <карта>` / `css_nominate` | номинировать карту (без аргумента — открывает меню) |
| `maps` / `css_maps` | список доступных карт |
| `css_rtv_status` | текущий статус голосования |

## Список карт (maps.txt)

Файл `maps.txt` создаётся автоматически рядом с плагином. Формат — одна карта на строку:

```
de_dust2                     # обычная карта
workshop:3070463151          # карта из Мастерской по ID
Моя карта|3070463151         # карта из Мастерской со своим названием
```

## Настройка

Порог голосов задаётся в коде — константа `VotePercent` (по умолчанию `0.6` = 60%).

## Сборка

Запусти `build.bat`. Готовый файл: `bin/Release/net8.0/RtvPlugin.dll` — положи папку плагина в `addons/counterstrikesharp/plugins/`.

## Требования

- CounterStrikeSharp
- CS2MenuManager (для меню голосования)
