# No Map Music

Плагин для Counter-Strike 2, который отключает встроенную музыку карт для всех игроков на сервере.

## Как это работает

Плагин отключает музыку двумя способами:

1. **Стандартная музыка CS2** — выставляет каждому игроку нулевую громкость музыкальных каналов (при заходе и на старте раунда).
2. **Музыка воркшоп/кастомных карт** (например `mg_100traps`) — перехватывает звуковые события карты и блокирует только те, чьи имена похожи на музыку (`music`, `song`, `theme`, `ambient_music` и т.п.). Звуки ловушек и триггеров при этом **не** затрагиваются.

## Требования

- Counter-Strike 2 сервер
- [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp)
- .NET 8.0 SDK (для компиляции)

## Установка

1. Скомпилируйте плагин:
   ```bash
   # Windows
   build.bat

   # Linux/Mac
   chmod +x build.sh
   ./build.sh
   ```

2. Скопируйте `NoMapMusicPlugin.dll` из `bin/Release/net8.0/` в:
   ```
   csgo/addons/counterstrikesharp/plugins/NoMapMusicPlugin/NoMapMusicPlugin.dll
   ```

3. Перезапустите сервер.

## Примечание

Плагин отключает музыку у игроков автоматически. Игрок при желании может вернуть музыку себе в настройках звука игры — это его личная громкость.
