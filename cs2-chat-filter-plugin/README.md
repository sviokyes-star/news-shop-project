# Chat Filter [Okyes]

Плагин для Counter-Strike 2, который убирает служебные сообщения карт из чата — например `Console: @ [football access granted!]` на `mg_100traps_r`.

## Как это работает

Плагин перехватывает сообщения чата и, если текст содержит любую из подстрок-фильтров, не показывает его игрокам. Обычные сообщения игроков не затрагиваются.

## Настройка (filters.txt)

Файл `filters.txt` создаётся автоматически рядом с плагином. Одна подстрока — одна строка, регистр не важен:

```
access granted
football
Console:
[MG]
```

Если строка сообщения содержит любую из подстрок — оно скрывается.

После правки файла примени изменения командой `css_chatfilter_reload` (без перезапуска сервера).

## Сборка

Запусти `build.bat`. Готовый файл: `bin/Release/net8.0/ChatFilterPlugin.dll` — положи папку плагина в `addons/counterstrikesharp/plugins/`.

## Требования

- CounterStrikeSharp
